# Logistic-Regression-Classification
Built a Logistic Regression model using Scikit-learn to classify breast cancer tumors. Evaluated performance using accuracy, precision, recall, confusion matrix, and ROC-AUC, and explored threshold tuning.

what I did?
-> used Breast Cancer Wisconsin Dataset.
->Split the data into training and testing sets.
->Standardized the features.
->Trained a Logistic Regression model.
->Made predictions.
->Calculated accuracy, precision, recall, and F1-score.
->Created a confusion matrix.
->Calculated ROC-AUC and plotted the ROC curve.
->Tuned the classification threshold and learned the sigmoid function.
